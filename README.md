混合缺失是对附件 2 验证集进行可复现的连续区间人工遮挡；六组完整结果及更严苛的缺失率、位置、长度分析见报告。R3 在清洁输入下保持基础模型输出，可靠性门控与一致性损失经消融后未保留。Neutral（中性类）仍是主要困难：R3 完整输入 F1 为 .4882，混合缺失 F1 为 .4498。这里只报告单 seed 结果，不作跨 seed 显著性声称。
