# Q1 与 Q2 论文材料包

本包对应主分支当前选定版本：Q1 的附件 1 全量 100 条特征工程；Q2 的最佳 BERT 基础模型及在同一权重上完成的 R0–R5 连续局部缺失消融。最终 R3 包含连续缺失训练、区间几何与局部重建；R4/R5 的可靠性残差和一致性约束仅作为未被选中的消融结果。

| 目录 | 内容 |
|---|---|
| `Q1/` | 特征提取与对齐代码、100 条特征 NPZ、逐样本和逐窗记录、典型图及审计报告 |
| `Q2/code/` | 完整训练、消融、紧凑参数还原、验证与附件 3 无标签推理代码及配置 |
| `Q2/model_parameters/` | BERT 后四层与下游参数的紧凑包、R3 局部模块增量；还原需公开 BERT 基础权重 |
| `Q2/results/clean_bert/` | 已选定基础模型的验证与既有一次 clean test 记录 |
| `Q2/results/ablation/` | R0–R5 原始验证指标、曲线、预测、类别/混淆矩阵与缺失专项表 |
| `Q2/figures/` | 缺失模态、比例、位置和长度的四张 PDF/SVG/PNG 图与中文图注 |

R3 原始参数在附件 2 官方 `valid` 上，clean Accuracy/Macro-F1/MAE/Pearson 为 `.6429/.6169/.6297/.6159`；固定混合局部缺失为 `.6195/.5920/.6686/.5631`。紧凑参数因量化而略有差异，`compact_validation_metrics.json` 有独立结果。既有一次 `test` 数值属于基础 clean BERT，R3 未重新评估 test。附件 3 的 30 条预测无标签，不能计算准确率；推理时使用的零值推断缺失候选并非官方缺失真值。

请先看 [完整复现指南](REPRODUCE_Q1_Q2.md) 与 [Q2 消融报告](Q2/Q2_BEST_MODEL_ABLATION.md)。赛题原始数据、Q1 基础模型及公开 BERT 基础权重不包含在包内；模型参数文件合计约 31.8 MiB，可在服务器准备基础权重后还原。论文写作时须区分原始参数与紧凑参数、validation 与 test、人工缺失验证与附件 3 无标签推理。
