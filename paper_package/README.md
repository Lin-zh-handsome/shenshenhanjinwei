# Q1 与 Q2 论文材料包

本包整理已完成的 Q1 全量代码与结果，以及 Q2 验证集分类表现最高且可从 `text_bert/audio/vision` 推理的 BERT 版本。数字均来自既有实验记录；本次整理没有重新训练或重新评估附件 2 的 `test`。附件 3 的 30 条无标签预测由已选定的 Q2 checkpoint 新生成。

## 目录

| 目录 | 内容 | 论文用途 |
|---|---|---|
| `Q1/` | 特征提取、对齐、验证代码；100 条特征 NPZ；逐样本和逐窗记录；图；配置与环境记录 | 问题一的方法、全量结果、典型样本和可复现说明 |
| `Q2/code/` | 选定 BERT 模型的训练、数据读取、验证、附件 3 推理与紧凑参数还原代码 | 问题二的已完成 clean 模型实现 |
| `Q2/model_parameters/` | 29.96 MiB 紧凑参数文件，保存微调后的 BERT 最后 4 层与全部下游参数 | 满足附件大小限制的模型参数材料 |
| `Q2/results/` | 验证集、既有单次 test、类别指标、预测、附件 3 全量预测与消融表 | 问题二的已完成实验依据 |

## 可以直接引用的结果

| 问题 | 指标 | 实际记录 |
|---|---|---|
| Q1 | 处理样本 | 100/100；统一 50 个真实时间窗 |
| Q1 | 特征形状 | 文本 `(100,50,128)`，音频 `(100,50,74)`，视觉 `(100,50,52)` |
| Q1 | 有效时间窗 | 文本 4038/5000，音频 4698/5000，视觉 3894/5000 |
| Q2 原始选定模型 | validation | Accuracy 0.6429，Macro-F1 0.6169，MAE 0.6297，Pearson 0.6159，Neutral F1 0.4882 |
| Q2 原始选定模型 | 既有一次 test | Accuracy 0.6657，Macro-F1 0.6025，MAE 0.6771，Pearson 0.6639，Neutral F1 0.3516 |
| Q2 紧凑参数还原 | validation | Accuracy 0.6415，Macro-F1 0.6164，MAE 0.6299，Pearson 0.6153 |

Q2 原始模型按 validation 上 `0.55 × Macro-F1 + 0.45 × Accuracy` 的分类排序选出；该式仅是实验中的选择规则，不是赛题官方总分。完整结果见 `Q2/README.md`。紧凑参数使用逐行 8 位量化，和原始 419 MB checkpoint（模型参数文件）并非逐位相同，因此论文引用原始模型指标时应引用 `Q2/results/metrics.json` 与既有 `test_metrics.json`，不要把紧凑版验证指标写成原始模型结果。

## 范围与论文写作边界

- Q1 的 100 条全量特征在 `Q1/q1_features.npz`；逐样本结果在 `q1_manifest.csv`，逐窗质量在 `q1_quality_report.csv`，典型样本图在 `Q1/figures/`。`word_boundary_coverage` 是词级时间边界覆盖率，不代表人工标注定位准确率。
- Q2 选定版本是三模态 **clean backbone（完整输入基础模型）**。其连续局部缺失鲁棒性模块没有完成有效的增量验证，不能把旧 SRF-MSA 的缺失鲁棒消融与此 BERT 版本合并称为同一模型的结果。
- `Q2/results/attachment3_predictions_best_bert.csv` 是原始选定模型对附件 3 的 30 条无标签预测；`attachment3_predictions_compact.csv` 是紧凑参数版的独立推理。两者类别一致，但强度值最大差约 0.0235。附件 3 无标签，不能报告 Accuracy/F1。
- 本包不含赛题原始音视频、附件 2 数据、预训练基础 BERT 权重或 Q3 材料。复现这些实验需合法取得赛题附件与公开基础权重。本包中的模型训练只使用赛题提供的 CMU-MOSEI 数据。
- 竞赛附件大小以 `Q1_Q2_paper_package.zip` 为准。本包已对文字材料检查参赛单位、队员姓名、队伍编号等身份字段；提交前仍需按最终论文与比赛平台要求复核。

Git 仓库原有 `E题/Q1/` 与 `E题/Q2/` 保存更完整的历史工程。这个压缩包集中提供写论文和提交所需的已完成材料，不覆盖原始实验记录。
