# 三问统一数学符号

| symbol | meaning | shape | problem |
|---|---|---|---|
| `B` | batch（批量）大小 | scalar | Q2,Q3 |
| `K` | Q1 统一时间窗数 | 50 | Q1 |
| `T_i` | 第 i 个视频有效时长 | scalar seconds | Q1 |
| `I_{i,k}` | 第 i 个视频第 k 个时间窗 | interval | Q1 |
| `X^T,X^A,X^V` | 文本、音频、视觉输入 | Q1 `[N,50,128/74/52]`; Q2/Q3 `[B,50,768/74/35]`（文本 Q2 先为 token） | Q1–Q3 |
| `M_m` | 模态 m 的有效/缺失位置掩码，使用时注明语义 | `[B,50]` | Q1–Q3 |
| `h_m` | 模态 m 的编码表示 | `[B,50,128]` | Q2,Q3 |
| `g_m` | 证据门输出 | `[B,50]` | Q3 |
| `p` | 三类预测概率 | `[B,3]` | Q2,Q3 |
| `\hat y` | 预测情感强度 | `[B]` | Q2,Q3 |
| `L_cls` | 分类交叉熵损失 | scalar | Q2,Q3 |
| `L_reg` | 回归损失 | scalar | Q2,Q3 |
| `L_rec` | 人工缺失处重建损失 | scalar | Q2 |
| `\Delta_m` | 删除模态 m 后的预测变化（LOMO） | `[B]` | Q3 |
| `s_e` | 局部证据综合分数 | scalar/span | Q3 |

Q1 的文本 128 维与 Q2/Q3 的原始文本 768 维不是同一输入。全文固定用 `X^T/X^A/X^V`，避免 `T` 同时表示时长和文本。
